Pompe à essence automatisée Arduino / Contrôle embarqué

Système embarqué qui simule une borne de station-service en libre-service. Il gère la validation de la carte avec code PIN, le verrouillage de nuit, la détection du pistolet, le débit de carburant en temps réel, le calcul du prix et l’impression d’un reçu sur l’écran LCD. L’objectif est de reproduire le parcours complet d’un client à la pompe automatique.

01. Parcours utilisateur Comment on fait le plein

  • Vérification d’ouverture : Un capteur de luminosité est lu. Si c’est “la nuit”, l’écran affiche « Closed Station » en boucle et la pompe est bloquée.
  • Insertion de la carte : Un capteur sur l’entrée 12 détecte si une carte est présente. Tant que la carte n’est pas insérée, la borne attend.
  • Saisie du code PIN : L’utilisateur tape un code à 4 chiffres sur un clavier matriciel 4x3. L’écran affiche les chiffres tapés mais masque progressivement les précédents avec « * ». Après 3 erreurs, la carte est bloquée.
  • Retirer la carte : Par sécurité, le plein ne peut pas démarrer tant que la carte est encore détectée. On doit retirer la carte avant d’accéder au carburant.
  • Prendre le pistolet : Une entrée numérique (pin 10) simule « pistolet décroché ». L’écran affiche « Veuillez prendre le pistolet… » tant qu’il est encore raccroché.
  • Appuyer pour distribuer : Tant que le pistolet est en main ET que le bouton pompe est maintenu appuyé, l’essence “coule”. Chaque seconde ajoute +2 L et met à jour en direct le volume servi et le prix total en euros.
  • Raccrocher le pistolet : Quand l’utilisateur remet le pistolet sur son support, la borne affiche un récapitulatif final (litres + prix), puis « À Bientôt ! ».

02. Sécurité & réalisme Comportement réel d’une pompe

  • Verrouillage de nuit : La pompe reste fermée si la luminosité ambiante est trop basse. C’est une simulation d’horaires d’ouverture.
  • Anti-fraude PIN : Code PIN sur 4 chiffres (« 7358 »). Après 3 essais échoués, la carte est refusée et marquée bloquée (kill = 1).
  • Obligation de retirer la carte : Le client doit retirer physiquement la carte avant de pouvoir se servir, comme sur les pompes CB en libre-service.
  • Détection du pistolet : On ne peut pas pomper tant que le pistolet n’est pas décroché, et il faut le raccrocher pour obtenir le ticket final.
  • Prix en direct : Le prix est recalculé en temps réel en fonction du volume réellement distribué et du tarif P_SP22 = 4.30 €/L.

03. Matériel & entrées/sorties Électronique

  • Clavier matriciel 4x3 câblé sur les broches numériques 22–28 pour la saisie du code PIN.
  • Écran LCD 16x2 sur les broches (8, 9, 2, 3, 5, 6) — affiche les instructions, les litres, le montant à payer.
  • Capteur de luminosité sur A1 — permet de déterminer si la station est “ouverte”.
  • Détection carte sur la broche 12 — indique si une carte est insérée ou retirée.
  • Détection pistolet sur la broche 10 — indique si le pistolet de carburant est décroché / raccroché.
  • Bouton pompe sur la broche 4 — simule la poignée qu’on maintient pour faire couler le carburant.

04. Logique principale Boucle temps réel Arduino

Ci-dessous un extrait simplifié de la boucle de distribution : toutes les 1000 ms pendant que l’utilisateur maintient la poignée, on ajoute +2 L, on met à jour le prix total, et on affiche les infos à l’écran. Le plein est plafonné à 45 L pour simuler la capacité du réservoir. 


// prix au litre
float P_SP22 = 4.30;

// plein = niveau actuel
// LPT   = niveau initial (aléatoire 0..60 L)
// prix  = coût actuel en €

if (LPT <= 40 && kill != 1) {
    lcd.clear();
    lcd.print("Veuillez prendre");
    lcd.setCursor(0,1);
    lcd.print("le pistolet...");

    // attendre que le pistolet soit pris
    while (digitalRead(10) == 0);

    lcd.clear();
    lcd.print("Appuyez pour demarrer");

    // tant que le pistolet est tenu
    while (digitalRead(10) == 1) {
        // si la gachette est appuyee
        if (digitalRead(4) == 1) {
            int debut_appui = millis();
            while (digitalRead(4) == 1 && plein < 45) {
                if (millis() - debut_appui >= 1000) {
                    plein += 2; // +2 L/s
                    prix = (plein - LPT) * P_SP22;

                    lcd.clear();
                    lcd.setCursor(0,0);
                    lcd.print(plein);
                    lcd.setCursor(10,0);
                    lcd.print(prix);
                    lcd.print("€");

                    debut_appui = millis();
                }
            }
            stop = 1;
        }
    }
}

À la fin, la pompe exige que le pistolet soit raccroché. Ensuite l’écran affiche le volume servi (en litres) et le prix final en euros, puis un message de fin : « A Bientot ! ».

05. Ce que j’ai appris Compétences

  • Sécurisation d’une interface argent / paiement : carte, code PIN, blocage après 3 essais.
  • Conception en machine d’états : « carte insérée → authentification → carte retirée → pistolet décroché → appui sur la poignée → remplissage → pistolet raccroché → reçu ».
  • Boucles temps réel sans delay() avec millis(), pour garder l’interface réactive pendant que le remplissage évolue.
  • Interaction homme-machine : messages clairs sur l’écran LCD à chaque étape, comme sur une vraie pompe 24/7 CB.
